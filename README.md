# Лабораторна робота № 1 — варіант 2

Вебзастосунок порівнює інтерполяційний поліном Лагранжа та поліноміальну апроксимацію методом найменших квадратів (МНК).

## Запуск

Відкрийте `index.html` у сучасному браузері. Сервер і сторонні бібліотеки не потрібні. Виберіть набір 5, 10 або 20: поле «Точки для графіка» відкриється з даними відповідного аркуша, а картка над керуванням покаже лише вибраний режим. Формат рядка: `1) [x; y],`. Змінюйте пари у полі — графік оновлюється під час введення. Кнопка «Набір варіанта» відновлює початкові значення вибраного аркуша.

## Набори даних

Набори варіанта 2 зчитано з відповідних аркушів файлу «Варіанти до ЛР № 1». Аркуш «5 точок» містить 5 пар, «10 точок» для варіанта 2 містить 8 пар, а «20 точок» — 20 пар. Для аркуша на 10 точок використано рівно ті 8 пар, що наведені у файлі, без додавання вигаданих значень.

## Реалізація

- `index.html` — структура інтерфейсу та елементи керування.
- `style.css` — оформлення й адаптивна сітка.
- `math.js` — розбір власних точок, Лагранж, поділені різниці Ньютона, МНК через QR Хаусхолдера, метрики та оцінка обумовленості.
- `app.js` — керування інтерфейсом, анімація, шість графіків, картки деталей для поточного набору та порівняльна таблиця 5/10/20 з RSS, R² і LOO-RMSE.
- `tests/algorithms.test.js` — тести алгоритмів і контроль метрик.

Вузол x нормалізується до [-1; 1] для МНК. Підсумковий розв'язок обчислюється QR-розкладом, без нормальних рівнянь. Межі осей обчислюються за точками та значеннями кривих.

## Перевірка

За наявності Node.js запустіть `npm test`. Тести перевіряють розбір власних точок, інтерполяцію у вузлах, МНК, LOO-RMSE, ортогональність залишків і метрики для наборів із 5, 10 та 20 точок.
